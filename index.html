Available Tools

AWC Intelligence Dashboard

12-page Power BI-style analytics dashboard — KPI tiles, drill-down charts, AWC profiles, data quality report, and data collection manager for all 706 AWC centres in Peddapalli District.

Open Dashboard →
📝

AWC Data Entry Form

ICDS field data entry form for AWC workers — cascading Project → Mandal → Sector → AWC selection with Google Sheet integration. Also opens pre-filled when sent from the dashboard.

Open Form →
How to use: Open the Dashboard to analyse all 706 AWC centres and generate shareable form links. Go to Collect Data (Page 12) in the dashboard to send pre-filled form links to AWC workers via WhatsApp. Configure Google Apps Script URL (Setup button) to enable live submission tracking.
