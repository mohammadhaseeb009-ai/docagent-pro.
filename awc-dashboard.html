The current master dataset contains only 5 fields: AWC ID, AWC Name, Project, Mandal, and Sector. Infrastructure details such as building type, water supply, electricity, kitchen, and toilet availability have not been collected yet.

To collect this data: Go to the Collect Data (Page 12) tab to generate shareable links for each AWC and send them to field workers.

Nutrition Dashboard (SAM/MAM)
Nutrition Data Not Available in Master Data

SAM (Severely Acute Malnutrition) and MAM (Moderately Acute Malnutrition) statistics require monthly beneficiary data collected from AWC workers. This data is not present in the current 5-field master dataset.

How to collect: Include nutrition fields (children 0-3, children 3-6, SAM cases, MAM cases, pregnant women) in the remarks field of the data entry form, or add new columns to your Google Sheet.

Google Apps Script – doGet (Live Data Fetch)

Add this function to your existing Apps Script to enable live data fetch in this dashboard:

function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet() .getActiveSheet(); var rows = sheet.getDataRange().getValues(); var headers = rows[0]; var data = rows.slice(1).map(function(r) { var obj = {}; headers.forEach(function(h, i) { obj[h] = r[i]; }); return obj; }); return ContentService .createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); }
Google Apps Script – doPost (Form Submission)
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet() .getActiveSheet(); var data = JSON.parse(e.postData.contents); var row = [data.timestamp, data.project, data.mandal, data.sector, data.awcName, data.awcId, data.remarks]; sheet.appendRow(row); return ContentService.createTextOutput('OK'); }
Steps: Open Google Sheet → Extensions → Apps Script → paste both functions → Deploy as Web App → Copy URL → paste into dashboard Setup.
